# Alder & Rue

A BudStacks storefront template on Template Design System v2, built from the
design handoff "Alder & Rue" (an invented clinician-led clinic with its own
pharmacy).

Upload: BudStacks super admin → Templates → Upload, with this repository's URL
and the template name **Alder and Rue** (the name becomes the slug
`alder-and-rue`).

Validate: `node <budstack-template-skill>/scripts/validate-template.mjs .`
